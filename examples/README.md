# Exemples

Un exemple complet rempli pour t'orienter sur le format attendu de chaque artefact.

## `freelance-devis/`

Petit projet fictif : **freelance qui automatise la génération de devis** à partir d'un formulaire site web.

Le dossier contient :

| Fichier | Produit par | À quoi ça sert |
|---|---|---|
| `PRD.md` | `/architect` | Le squelette de référence : sommaire, utilisateurs, MVP, hors-MVP, phases, stack, critères |
| `DESIGN.md` | `/design` | Le design system rempli (palette chaude humaniste, typo serif+sans, 9 composants) |
| `phase-1-plan.md` | `/plan` | Plan détaillé d'UNE phase (5 tâches, critères "Fait quand" vérifiables) |
| `CLAUDE.md` *(extrait)* | `/start` + manuel | À quoi ressemble Identité + Stack remplis après `/start` puis `/architect` |

Ouvre ces fichiers en parallèle de tes propres essais — le format est plus parlant qu'une longue doc.

> Note : c'est un projet illustratif. Tu n'as **pas** à reproduire ce projet ni à utiliser la même stack. Le kit s'adapte à ton cas.
